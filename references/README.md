# Quanta Study reference-table metadata index

Part of the Quanta Study compact-reference dataset by AM Creative Tech UG (haftungsbeschränkt). This index contains 19 main tables and 14 supplements: **33 metadata entries, zero table rows or cell values**. It is counted separately from formulas.

Use [reference-index.json](./reference-index.json) with its [schema](./reference-index.schema.json). It supplies IDs, bilingual DE/EN titles and groups, source/edition metadata, columns, source row counts and canonical/navigation URLs. A rowCount is only a count; it supplies no cell values. Supplement dates/editions come from their parent table and are not a separate supplementary review.

URLs follow the source routing contract; no live HTTP availability check is claimed by this export. No table descriptions, source notes, articles, worked examples, FAQs, blueprints, images, downloads or calculators are included. Follow the canonical links or [Tafelwerk hub](https://quanta-study.de/tafelwerk) to read online.
